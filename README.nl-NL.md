# 🚀 Functies
- Snelle snelheidsaanpassing
- Moderne UI
- Ondersteunt zowel x86- als x64-platformprocessen
- Geen kernelinbreuk — Ring3-niveau hooking, tast de systeemkernel niet aan


# 💾 Installatie
📦 **Methode 1: Winget**

``` powershell
# Installatieopdracht
winget install openspeedy

# Open een nieuwe terminal en voer openspeedy uit
openspeedy
```

📥 **Methode 2: Handmatig downloaden**

Bezoek de [releasespagina](https://github.com/game1024/OpenSpeedy/releases) om de nieuwste versie te downloaden.


🎮 **Methode 3: Steam (optioneel)**

Verkrijgbaar in de [Steam-winkel](https://store.steampowered.com/app/5010920/OpenSpeedy). Dit is een optionele installatiemethode.


# 💻 Systeemvereisten
- OS: Windows 10 of later
- Platform: x86 (32-bit) en x64 (64-bit)

# 🔧 Hoe het werkt

Vereisten voor bouwen:
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)
- [CMake](https://cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/) (met C++ desktopontwikkelingsworkload)

Bouwopdracht:

``` powershell
npm run tauri dev
```

OpenSpeedy past de spelsnelheid aan door de volgende Windows-systeemtijdfuncties te hooken:

| Functie | Bibliotheek | Doel |
|----------|---------|---------|
| Sleep | user32.dll | Thread-slaapstand |
| SetTimer | user32.dll | Maakt berichtgebaseerde timers |
| timeGetTime | winmm.dll | Haalt systeemuptime op in milliseconden |
| GetTickCount | kernel32.dll | Haalt systeemuptime op in milliseconden |
| GetTickCount64 | kernel32.dll | Haalt systeemuptime op in milliseconden (64-bit) |
| QueryPerformanceCounter | kernel32.dll | Hoge-resolutie prestatieteller |
| GetSystemTimeAsFileTime | kernel32.dll | Haalt systeemtijd op |
| GetSystemTimePreciseAsFileTime | kernel32.dll | Haalt zeer nauwkeurige systeemtijd op |
| SetWaitableTimer | kernel32.dll | Stelt een wachtbare timer in |
| SetWaitableTimerEx | kernel32.dll | Stelt een wachtbare timer in (uitgebreid) |

# ⚠️ Waarschuwingen
- Deze tool is alleen voor educatieve en onderzoeksdoeleinden
- Sommige online games hebben anti-cheatsystemen — gebruik van deze tool kan leiden tot accountbans
- Overmatige snelheid kan fouten in de physics-engine of crashes veroorzaken
- Niet aanbevolen voor gebruik in competitieve online games
- Open-sourcesoftware zonder digitale handtekeningen kan valse meldingen van antivirussoftware veroorzaken
