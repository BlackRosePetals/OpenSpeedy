# 🚀 Возможности
- Быстрое изменение скорости
- Современный интерфейс
- Поддержка x86 и x64 процессов
- Без вмешательства в ядро — хукинг на уровне Ring3, не нарушает работу системы


# 💾 Установка
📦 **Способ 1: Winget**

``` powershell
# Команда установки
winget install openspeedy

# Откройте новый терминал и запустите openspeedy
openspeedy
```

📥 **Способ 2: Ручная загрузка**

Посетите [страницу релизов](https://github.com/game1024/OpenSpeedy/releases), чтобы скачать последнюю версию.


🎮 **Способ 3: Steam (необязательно)**

Доступно в [магазине Steam](https://store.steampowered.com/app/5010920/OpenSpeedy). Это необязательный способ установки.


# 💻 Системные требования
- ОС: Windows 10 или новее
- Платформа: x86 (32-бит) и x64 (64-бит)

# 🔧 Принцип работы

Необходимые инструменты для сборки:
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)
- [CMake](https://cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/) (с рабочей нагрузкой C++ для разработки настольных приложений)

Команда сборки:

``` powershell
npm run tauri dev
```

OpenSpeedy изменяет скорость игры, перехватывая следующие системные функции времени Windows:

| Функция | Библиотека | Назначение |
|----------|---------|---------|
| Sleep | user32.dll | Приостановка потока |
| SetTimer | user32.dll | Создание таймеров на основе сообщений |
| timeGetTime | winmm.dll | Получение времени работы системы в миллисекундах |
| GetTickCount | kernel32.dll | Получение времени работы системы в миллисекундах |
| GetTickCount64 | kernel32.dll | Получение времени работы системы в миллисекундах (64-бит) |
| QueryPerformanceCounter | kernel32.dll | Высокоточный счётчик производительности |
| GetSystemTimeAsFileTime | kernel32.dll | Получение системного времени |
| GetSystemTimePreciseAsFileTime | kernel32.dll | Получение высокоточного системного времени |
| SetWaitableTimer | kernel32.dll | Установка ожидаемого таймера |
| SetWaitableTimerEx | kernel32.dll | Установка ожидаемого таймера (расширенная) |

# ⚠️ Предупреждения
- Этот инструмент предназначен только для образовательных и исследовательских целей
- Некоторые онлайн-игры имеют системы античита — использование может привести к блокировке аккаунта
- Чрезмерное ускорение может вызвать сбои физического движка или падение игры
- Не рекомендуется для использования в соревновательных онлайн-играх
- ПО с открытым исходным кодом без цифровой подписи может вызывать ложные срабатывания антивирусов
