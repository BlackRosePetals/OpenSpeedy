# 🔧 यह कैसे काम करता है

बिल्ड के लिए आवश्यकताएँ:
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)
- [CMake](https://cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/) (C++ डेस्कटॉप डेवलपमेंट वर्कलोड के साथ)

बिल्ड कमांड:

``` powershell
npm run tauri dev
```

OpenSpeedy निम्नलिखित Windows सिस्टम समय फ़ंक्शनों को हुक करके गेम की गति को समायोजित करता है:

| फ़ंक्शन | लाइब्रेरी | उद्देश्य |
|----------|---------|---------|
| Sleep | user32.dll | थ्रेड स्लीप |
| SetTimer | user32.dll | मैसेज-आधारित टाइमर बनाता है |
| timeGetTime | winmm.dll | सिस्टम अपटाइम मिलीसेकंड में प्राप्त करता है |
| GetTickCount | kernel32.dll | सिस्टम अपटाइम मिलीसेकंड में प्राप्त करता है |
| GetTickCount64 | kernel32.dll | सिस्टम अपटाइम मिलीसेकंड में प्राप्त करता है (64-बिट) |
| QueryPerformanceCounter | kernel32.dll | उच्च-रिज़ॉल्यूशन प्रदर्शन काउंटर |
| GetSystemTimeAsFileTime | kernel32.dll | सिस्टम समय प्राप्त करता है |
| GetSystemTimePreciseAsFileTime | kernel32.dll | उच्च-सटीकता सिस्टम समय प्राप्त करता है |
| SetWaitableTimer | kernel32.dll | प्रतीक्षा योग्य टाइमर सेट करता है |
| SetWaitableTimerEx | kernel32.dll | प्रतीक्षा योग्य टाइमर सेट करता है (विस्तारित) |

# ⚠️ चेतावनियाँ
- यह टूल केवल शैक्षिक और अनुसंधान उद्देश्यों के लिए है
- कुछ ऑनलाइन गेम में एंटी-चीट सिस्टम होते हैं — इस टूल का उपयोग करने पर अकाउंट बैन हो सकता है

- प्रतिस्पर्धी ऑनलाइन गेम में उपयोग की अनुशंसा नहीं की जाती
- डिजिटल हस्ताक्षर के बिना ओपन-सोर्स सॉफ़्टवेयर एंटीवायरस से गलत चेतावनियाँ उत्पन्न कर सकता है
